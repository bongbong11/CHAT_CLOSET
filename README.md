# 👕 끼끼의상실

SillyTavern 캐릭터·페르소나의 취향, 옷장, 현재 착장을 관리하는 클라이언트 확장입니다. 별도 서버 플러그인은 필요하지 않습니다.

## 설치

실리의 **확장 → 확장 설치**에 아래 주소를 넣으세요.

```text
https://github.com/bongbong11/CHAT_CLOSET
```

설치 후 실리를 새로고침하고 **👕 끼끼의상실**을 여세요. 설정의 **사용함**을 켜고 **연결 프로필**을 선택한 뒤 연결 확인을 실행합니다. 모델은 실리 Connection Manager 프로필의 모델·연결을 그대로 사용합니다. 이 확장에 API 키를 별도로 저장하지 않습니다.

## 시작하기

1. 개별 캐릭터 채팅을 엽니다. 그룹 채팅은 현재 지원하지 않습니다.
2. 선택지에서 분석 대상과 읽을 로어북을 고릅니다.
3. **취향 분석**으로 캐시트·페르소나·선택 로어북을 분석합니다. 기억이나 과거 채팅은 초기 취향 분석에 사용하지 않습니다.
4. **취향 보기**에서 결과를 수정할 수 있습니다. 사용자 수정값은 재분석 때 보존합니다.
5. 인포블록 템플릿에서 모델에게 전달되는 위치에 아래 두 줄을 한 번 넣습니다. 화면에만 표시되는 템플릿이면 주입되지 않습니다.

```text
<kikki_outfit>
</kikki_outfit>
```

태그 사이에는 확장이 확정한 **착장 내용만** 들어갑니다. 분석 근거나 선택 지시는 주입하지 않습니다. 태그가 최종 모델 요청에 없으면 UI에 오류를 표시합니다. 원본 템플릿이나 채팅 메시지의 태그를 주입 과정에서 덮어쓰지 않고, 보내는 요청 안에서 치환합니다.

## 답변에 내부 착장을 표시하지 않음

`<kikki_outfit>…</kikki_outfit>`은 내부 참고용입니다. 모델이 이를 답변에 복사해도 블록 전체를 제거합니다. 스트리밍 중 아직 닫히지 않은 태그와 부분적으로 출력된 태그도 표시 전에 숨깁니다. 완료 후 저장되는 답변과 스와이프에서도 블록을 제거합니다. 일반 서술 속 의상 묘사는 유지합니다.

최신 실리에서는 공식 메시지 포맷터 훅을 사용합니다. 구버전에서는 실리 기본 **Regex 확장**을 통해 같은 필터를 설치합니다. 둘 다 사용할 수 없다면 착장 주입 생성을 중단하고 오류를 표시합니다. 별도 Regex 플러그인을 설치할 필요는 없습니다. 사용자 정규식은 수정하지 않으며 전체 데이터 삭제 시 확장이 설치한 규칙만 제거합니다.

## 착장과 씬

- 같은 씬에서는 옷의 색·소재·핏 등 고유 특징을 유지합니다.
- 준비·출발·시간 경과를 읽고 필요한 항목을 추가·제거·교체합니다. 계획만으로 바로 갈아입히지 않습니다.
- 맨발이라는 이전 상태만으로 평범한 외출에도 맨발을 강제하지 않습니다. 명시적으로 맨발로 나가는 행동은 우선합니다.
- 보유 옷을 재조합하고 필요한 경우 새 아이템을 추가합니다. 나이대·직업·생활수준·생활습관·브랜드 성향·최근 조합을 참고합니다. 분석한 작품명·세계관, 장소·소속별 복식 규칙과 세계관별 후보 목록을 판독에도 전달합니다. 해리포터 같은 설정을 일반 중세 판타지로 취급하거나 모든 장소에서 로브를 강제하지 않습니다. 로어북·캐시트의 AU와 시대 변경 설정을 우선합니다. 문화권과 시대·세계관 고증이 우선이며 현대 브랜드는 그 배경에 맞을 때만 씁니다. 판타지는 해당 설정의 소재·제작·복식 규칙을 따르고 특정 공방 이름이나 브랜드를 강제하지 않습니다. 보유 아이템의 브랜드는 유지합니다.
- 현재 상태, 이전 상황 5개, 최근 착장 조합 10개를 관리합니다. 복원용 체크포인트는 별도입니다.
- 완전 탈의가 확인된 인물의 주입은 생략합니다. 같은 상황에서는 판독을 줄이고 재착용·이동 등 변화가 있으면 재개합니다.
- 리롤·스와이프·편집·숨김에서 현재 활성 문맥으로 상태를 복원합니다. 화면만 숨긴 메시지와 모델 문맥에서 제외한 메시지를 구분합니다.

## 저장과 브랜치

캐릭터마다 기본 취향·옷장을 저장하고 스토리별 브랜치에 현재 착장, 페르소나 프로필, 추가 옷, 상태·복원 이력을 저장합니다. 새 채팅에는 **새 브랜치 / 현재 상태 복제 / 기존 브랜치 이어가기**로 연결하세요. 브랜치 변화가 기본 프로필에 자동 반영되지는 않습니다.

데이터는 현재 브라우저·실리 주소의 `localStorage`에 **`kikki-closet:v1` 한 키**로 저장합니다. 서버 파일·외부 DB·임시 파일을 만들지 않습니다. 다른 브라우저나 주소로는 자동 동기화되지 않으며 같은 브라우저·같은 주소를 함께 쓰면 저장 영역도 공유합니다.

설정에서 현재 채팅 데이터, 브랜치, 캐릭터 전체, 전체 데이터를 삭제할 수 있습니다. 공유 브랜치에서 현재 채팅을 초기화하면 해당 채팅을 분리해 다른 채팅은 보존합니다. 초기화 뒤에는 판독 재개 또는 분석을 눌러 다시 시작합니다.

실리의 채팅 삭제 이벤트를 받으면 연결을 제거하고 마지막 연결이 사라진 브랜치는 삭제합니다. 기본 프로필은 유지합니다. 외부에서 채팅 파일을 직접 지운 경우에는 이벤트가 발생하지 않으므로 브랜치 관리에서 삭제하세요. 채팅 이름 변경도 연결에 반영합니다.

삭제·브랜치 전환·판독 취소 뒤 늦게 도착한 응답은 저장하지 않습니다. 전체 삭제는 저장 키, 메모리 데이터, 처리 중인 요청, 관리 필터를 정리합니다. 다른 확장의 데이터와 일반 과거 채팅 내용은 삭제하지 않습니다.

## 화면

다이어리 태그 형태의 선택지·현재 착장 탭, 모바일 취향 프로필의 캐릭터·페르소나 탭, 작은 착장 글씨와 좁은 행 간격을 사용합니다. 본 화면은 씬판독기와 같은 최대 폭 760px이며 네이티브 모달로 채팅 위 중앙에 표시됩니다. 모바일은 화면 폭과 높이에 맞춰 줄어들고 내용만 스크롤됩니다.

끼끼를 누르면 입 열린 얼굴과 작은 말풍선에서 착장을 확인합니다. 애니메이션은 없습니다. 판독 중에는 테마에 맞는 중앙 토스트 **“의상을 맞춰보고 있습니다”**만 표시합니다.

## 검증

Node.js 22 이상:

```text
npm install
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

핵심 테스트는 주입·복원·삭제·응답 경쟁·출력 차단을 검증합니다. 브라우저 테스트는 실제 확장 진입점을 실리 API 테스트 호스트에서 실행하여 연결·분석·모바일 모달·스와이프·숨김·수정·삭제를 확인합니다. 유료 모델의 실제 답변 품질이나 사용자의 개별 인포블록 템플릿은 자동 테스트의 범위 밖이며 설치 후 연결 확인과 주입 미리보기에서 확인하세요.

끼끼 얼굴은 마우스나 손가락으로 끌어서 이동할 수 있습니다. 위치는 저장되며 화면 크기가 바뀌면 화면 안에 맞춰 조정됩니다. 짧게 누르면 착장 말풍선이 열립니다.
