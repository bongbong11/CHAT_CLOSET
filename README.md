# 끼끼의상실

SillyTavern 캐릭터·페르소나의 취향, 옷장, 현재 착장을 관리하는 클라이언트 확장입니다. 별도 서버 플러그인은 필요하지 않습니다.

## 설치

실리의 **확장 → 확장 설치**에 아래 주소를 넣으세요.

```text
https://github.com/bongbong11/CHAT_CLOSET
```

설치 후 실리를 새로고침하고 마법봉 메뉴의 **끼끼 얼굴 · 끼끼의상실**을 여세요. 설정의 **사용함**을 켜고 **SillyTavern 연결 프로필**을 선택한 뒤 연결 확인을 실행합니다. 모델은 실리 Connection Manager 프로필의 모델·연결을 그대로 사용합니다. 이 확장에 API 키를 별도로 저장하지 않습니다.

## 시작하기

1. 개별 캐릭터 채팅을 엽니다. 그룹 채팅은 현재 지원하지 않습니다.
2. 선택지에서 **캐릭터 또는 페르소나** 중 분석 대상을 먼저 고릅니다.
3. **분석 자료 가져오기**를 열면 선택한 대상의 자료만 표시됩니다. 캐릭터는 카드의 캐릭터 설명과 성격 요약을, 페르소나는 현재 페르소나 시트를 각각 가져옵니다.
4. 해당 대상에 연결된 로어북을 불러오고 필요한 엔트리만 체크한 뒤 **이 자료로 취향 분석**을 누릅니다. 기억이나 과거 채팅은 초기 취향 분석에 사용하지 않습니다.
5. **취향 보기**에서 영어 분석 보고서를 읽습니다. 캐릭터·페르소나 탭 옆의 작은 **번역하기** 버튼으로 자연스러운 한국어 번역과 원문을 전환합니다. 번역은 연결 모델을 사용하며 원문이나 주입 내용을 덮어쓰지 않습니다. **원문 수정**을 누르면 여러 줄 입력칸으로 수정할 수 있습니다. 사용자 수정값은 재분석 때 보존합니다.
6. 모델에게 전달되는 프롬프트의 참고 자료 위치에 아래 두 줄을 한 번 넣습니다. 답변으로 출력하도록 지시하는 인포블록 양식 바깥에 두세요. 기존 인포블록에서 의상 출력 항목도 제거합니다. 화면에만 표시되는 템플릿이면 주입되지 않습니다.

```text
<kikki_outfit>
</kikki_outfit>
```

태그 사이에는 **색·옷 이름·브랜드로 줄인 현재 착장과 출력 금지 문구**만 들어갑니다. 저장값은 이전 장면의 참고 정보이며 현재 인풋·아웃풋의 실제 이야기가 우선합니다. 저장된 착장을 유지하거나 바꾸기 위한 행동·이유를 롤플에 만들어내지 않도록 지시합니다. 착장 목록이나 의상 섹션을 답변에 만들지 말고, 장면에 필요한 의상 세부사항만 활용하도록 지시합니다. 취향 분석·옷장 전체·날씨·변경 이유는 주입하지 않습니다. 화면의 표시 디테일을 높여도 주입은 짧게 유지합니다. 태그가 최종 모델 요청에 없으면 UI에 오류를 표시합니다. 원본 템플릿이나 채팅 메시지를 덮어쓰지 않고 보내는 요청 안에서 치환합니다.

## 답변에 내부 착장을 표시하지 않음

`<kikki_outfit>…</kikki_outfit>`은 내부 참고용입니다. 모델이 이를 답변에 복사해도 블록 전체를 제거합니다. 스트리밍 중 아직 닫히지 않은 태그와 부분적으로 출력된 태그도 표시 전에 숨깁니다. 완료 후 저장되는 답변과 스와이프에서도 블록을 제거합니다. 일반 서술 속 의상 묘사는 유지합니다.

최신 실리에서는 공식 메시지 포맷터 훅을 사용합니다. 구버전에서는 실리 기본 **Regex 확장**을 통해 같은 필터를 설치합니다. 둘 다 사용할 수 없다면 착장 주입 생성을 중단하고 오류를 표시합니다. 별도 Regex 플러그인을 설치할 필요는 없습니다. 사용자 정규식은 수정하지 않으며 전체 데이터 삭제 시 확장이 설치한 규칙만 제거합니다.

## 착장과 씬

- 롤플 생성 전에는 저장된 착장만 즉시 주입하며 판독 모델을 호출하거나 기다리지 않습니다. 롤플 답변이 끝난 뒤 확장의 연결 모델이 채팅을 읽고 결과를 확장 내부에 저장합니다. 롤플 모델에게 확장용 JSON이나 의상 목록을 생성시키지 않습니다.
- 같은 장소의 일반 대화와 처리된 메시지는 모델 호출 없이 유지합니다. 새 메시지의 환복·이동·상당한 시간 경과, 인포블록의 장소·날짜·날씨 변화 단서를 확인해 필요한 경우 판독합니다. 단서 판정은 코드 규칙이므로 간접적인 표현을 놓쳤다면 **현재 옷 보기**로 다시 판독할 수 있습니다. 생성 도중 이벤트와 중복 완료 이벤트는 반복 호출하지 않습니다. 모델의 생각 예산을 줄이기 위해 출력 한도를 낮추지는 않았습니다.
- 같은 씬에서는 옷의 색·소재·핏 등 고유 특징을 유지합니다.
- 기본 착장 표시는 **색 + 옷 이름**으로 짧게 표시하고 여러 옷은 한 줄씩 나눕니다. 소재와 구조는 **표시 디테일 → 자세히**에서만 붙습니다. 브랜드 표시를 켜면 별도 작은 줄에 표시합니다. 새 기성복은 SPA 브랜드를 포함해 세계관·시대·생활수준에 맞는 브랜드를 정하고, 중고품은 원래 브랜드를 유지합니다. 수제품은 제작 방식·공방 정보를 씁니다. 기존 옷의 빠진 브랜드는 **현재 옷 보기**로 판독할 때 보완하며, 이미 있는 브랜드는 바꾸지 않습니다.
- 준비·출발·시간 경과를 읽고 필요한 항목을 추가·제거·교체합니다. 계획만으로 바로 갈아입히지 않습니다.
- 인풋과 아웃풋의 실제 이야기에서 명시된 착장·행동은 모두 우선합니다. 이전의 맨발·탈의를 다음 장면의 고정 조건으로 취급하지 않습니다. 사적인 장면이 끝나고 로비·식당·거리·업무 등으로 넘어갈 때 정상적인 준비 여유가 있으면, 의상 설명이 생략돼도 확장 모델이 재착용을 추론합니다. 같은 방·소파·욕실 이동, 계속되는 탈의 활동, 급박한 상황, 현재 이야기의 명시적 맨발·알몸 이동은 구별합니다. 이 판단은 내부 착장 상태만 갱신하며 이미 나온 롤플 답변을 바꾸거나 환복 서술을 요구하지 않습니다.
- 탈의 직전 착장과 최근 몸을 갖춰 입은 착장을 인물별로 보관해 재착용 때 우선 참고합니다. 리롤·스와이프·숨김 복원과 함께 되돌리고, 현재 채팅 초기화 시 함께 비웁니다. 오래된 데이터는 남아 있는 상태 이력에서 복원 정보를 추출합니다.
- 보유 옷을 재조합하고 필요한 경우 새 아이템을 추가합니다. 나이대·직업·생활수준·생활습관·브랜드 성향·최근 조합을 참고합니다. 분석한 작품명·세계관, 장소·소속별 복식 규칙과 세계관별 후보 목록을 판독에도 전달합니다. 해리포터 같은 설정을 일반 중세 판타지로 취급하거나 모든 장소에서 로브를 강제하지 않습니다. 로어북·캐시트의 AU와 시대 변경 설정을 우선합니다. 문화권과 시대·세계관 고증이 우선이며 현대 브랜드는 그 배경에 맞을 때만 씁니다. 판타지는 해당 설정의 소재·제작·복식 규칙을 따르고 특정 공방 이름이나 브랜드를 강제하지 않습니다. 보유 아이템의 브랜드는 유지합니다.
- 현재 상태, 이전 상황 5개, 최근 착장 조합 10개를 관리합니다. 복원용 체크포인트는 별도입니다.
- 완전 탈의가 확인된 인물의 주입은 생략합니다. 같은 상황에서는 판독을 줄이고 재착용·이동 등 변화가 있으면 재개합니다.
- 리롤·스와이프·편집·숨김에서 현재 활성 문맥으로 상태를 복원합니다. 화면만 숨긴 메시지와 모델 문맥에서 제외한 메시지를 구분합니다.

## 옷장 구성

**현재 착장 → 옷장 · 착장 수정**에서 캐릭터·페르소나를 선택하고 **상의 / 하의 / 겉옷 / 신발 / 속옷 / 액세서리·소품** 탭으로 보유 옷을 확인합니다. 카드에는 짧은 이름·색·브랜드와 착용 표시만 있습니다. 상세 펼치기는 없습니다. 카테고리나 인물을 바꿔도 편집 중인 선택은 유지하며 **착장 저장**으로 확정합니다. PC는 세 열, 모바일은 두 열이고 목록만 스크롤됩니다.

**선택지 → 기본 옷장 구성**은 전체 16개 대신 주요 카테고리별 **적게 / 중간 / 많이**를 정합니다.

| 카테고리 | 적게 | 중간 | 많이 |
|---|---:|---:|---:|
| 상의 | 4종 | 7종 | 10종 |
| 하의 | 3종 | 5종 | 7종 |
| 겉옷 | 1종 | 3종 | 5종 |
| 신발 | 2종 | 3종 | 5종 |

이 값은 다음 취향 분석의 초기 구성 목표입니다. 구별되는 옷 종류를 세며, 속옷·양말·벨트·장신구는 필요한 종류만 구성합니다. 같은 기본 양말 여러 켤레를 각각 생성하지 않습니다. 명시적인 보유 제한 또는 세계관상 필요 없는 종류는 이유와 함께 예외로 둘 수 있습니다. 분석 결과가 목표에 부족하면 해당 주요 종류만 한 번 보완하고, 그래도 부족하면 기존 데이터와 옷장을 보존하며 오류를 알립니다.

기존 옷과 이야기에서 추가된 옷은 목표 수를 넘어도 유지합니다. 설정을 줄여도 자동 삭제하지 않습니다. 기존 10/16/24개 설정은 각각 카테고리별 적게/중간/많이로 이전합니다. 긴 취향 설명·근거·소재·구조·판독 메모는 새 생성부터 영어로 보관하고, 롤플에는 짧은 착장만 주입합니다.

## 저장과 브랜치

캐릭터마다 기본 취향·옷장을 저장하고 스토리별 브랜치에 현재 착장, 페르소나 프로필, 추가 옷, 상태·복원 이력을 저장합니다. 새 채팅에는 **새 브랜치 / 현재 상태 복제 / 기존 브랜치 이어가기**로 연결하세요. 브랜치 변화가 기본 프로필에 자동 반영되지는 않습니다.

**1.3.0부터 같은 실리 서버·계정의 PC와 모바일이 서버 저장소를 공유합니다.** 설정 변경과 분석·판독 결과는 자동 저장합니다. 직접 수정 중인 보고서·착장은 해당 편집 화면의 저장 버튼으로 확정합니다. 확장 탭과 설정에 `서버에 저장 중… / 서버 저장됨 / 저장 오류` 상태가 표시됩니다. 저장 완료 후 기기를 바꾸세요. 접속·화면 복귀 시, 그리고 화면이 열린 동안 15초마다 다른 기기의 변경을 확인합니다. 롤플 생성은 이 동기화를 기다리지 않습니다.

실리의 [기본 파일 API](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/files.js)를 사용하며, 계정별 `data/<계정>/user/files/kikki-closet-state.json` **파일 하나만 덮어씁니다.** 서버 플러그인, 별도 DB, 채팅별 조각 파일, 확장 자체 백업 파일을 만들지 않습니다. 브라우저에는 새 옷장 데이터를 저장하지 않습니다. 다른 서버 또는 다른 실리 계정과는 공유하지 않습니다.

업데이트할 때는 **기존 데이터가 있는 PC 브라우저에서 먼저 새로고침**하세요. 서버 저장소가 아직 없으면 기존 `kikki-closet:v1` 데이터를 옮기고 서버 저장·재조회가 성공한 뒤에만 브라우저 원본을 지웁니다. 모바일에서 먼저 서버 저장소를 만들었다면 PC 설정의 **이 브라우저의 이전 데이터 가져오기**를 누르세요. 기존 서버 브랜치를 덮지 않고 겹치는 옛 브랜치는 별도로 가져오므로 브랜치 관리에서 이어갈 수 있습니다. 서버 오류 시 기존 데이터는 보존하며 **서버 다시 연결**로 재시도합니다.

저장 요청은 순서대로 처리하고 저장 전후 서버 변경을 검사합니다. 다른 기기의 변경이 확인되면 덮어쓰지 않고 최신 내용을 불러옵니다. 다만 실리 기본 파일 API에는 원자적 조건부 저장·기기 간 잠금이 없으므로 두 기기가 정확히 동시에 편집하는 경우까지 충돌 방지를 보장하지는 않습니다. 한 기기에서 저장 완료 후 다른 기기로 이어 쓰는 방식으로 사용하세요.

설정에서 현재 채팅 데이터, 브랜치, 캐릭터 전체, 전체 데이터를 삭제할 수 있습니다. 공유 브랜치에서 현재 채팅을 초기화하면 해당 채팅을 분리해 다른 채팅은 보존합니다. 초기화 뒤에는 현재 옷 보기 또는 분석을 눌러 다시 시작합니다.

실리의 채팅 삭제 이벤트를 받으면 연결을 제거하고 마지막 연결이 사라진 브랜치는 삭제합니다. 기본 프로필은 유지합니다. 외부에서 채팅 파일을 직접 지운 경우에는 이벤트가 발생하지 않으므로 브랜치 관리에서 삭제하세요. 채팅 이름 변경도 연결에 반영합니다.

삭제·브랜치 전환·판독 취소 뒤 늦게 도착한 응답은 저장하지 않습니다. 전체 삭제는 서버 파일의 모든 설정·프로필·옷장·브랜치 기록, 메모리 데이터, 처리 중인 요청, 관리 필터를 정리합니다. 같은 파일 안에는 비어 있음을 나타내는 버전 번호만 남깁니다. 이 표시는 오래된 기기의 데이터가 되살아나는 것을 막기 위한 것으로 의상이나 대화 기록은 포함하지 않습니다. 다른 기기의 이전 브라우저 저장 키도 그 기기가 다시 접속해 삭제 상태를 확인하면 제거합니다. 다른 확장의 데이터와 일반 과거 채팅 내용은 삭제하지 않습니다.

## 화면

다이어리 태그 형태의 선택지·현재 착장 탭, 모바일 취향 프로필의 캐릭터·페르소나 탭, 작은 착장 글씨와 좁은 행 간격을 사용합니다. 메모지는 원본의 2:3 비율과 탭 사이의 크기를 유지하며 최대 폭 520px의 네이티브 모달로 채팅 위 중앙에 표시됩니다. 모바일은 화면 폭과 높이에 맞춰 비율대로 줄어들고 종이 안의 내용만 스크롤됩니다. 밝은 테마와 어두운 테마 모두 종이 무늬와 글자가 보이도록 표시합니다.

모델 지시문, 새 분석값, 새 착장 설명은 영어를 사용합니다. 기존에 저장한 한국어 기록은 자동으로 덮어쓰지 않으며 새 분석부터 영어로 생성합니다. 보고서는 긴 문장과 근거를 줄바꿈하여 표시하고 본문 전체를 스크롤할 수 있습니다. 잘못된 JSON 응답은 한 번 교정을 시도하며, 실패하면 기존 데이터를 유지하고 한국어 안내를 표시합니다.

현재 착장의 **현재 옷 보기** 버튼은 채팅을 즉시 판독해 착장을 미리 보여줍니다. 설정의 **읽을 최근 채팅 턴 수**는 1~50턴, 기본 8턴입니다. 사용자 메시지와 이어지는 답변을 1턴으로 세며, 저장된 현재 상태와 최근 이력도 참고합니다. 이미 처리한 문맥과 새 행동을 구분하므로 다시 보기를 눌러도 같은 구매 등을 새 사건으로 반복 적용하지 않도록 판독합니다. PC에서는 착장 설명을 크게, 모바일에서는 작고 조밀하게 표시합니다.

끼끼를 누르면 입 열린 얼굴과 작은 말풍선에서 착장을 확인합니다. 애니메이션은 없습니다. 실제 판독 중에만 화면 오른쪽 아래에 작은 토스트 **“의상을 맞춰보고 있습니다”**를 표시합니다. 누르면 안내만 사라지고 판독은 계속됩니다.

## 검증

Node.js 22 이상:

```text
npm install
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

핵심 테스트는 주입·복원·삭제·응답 경쟁·출력 차단을 검증합니다. 브라우저 테스트는 실제 확장 진입점을 실리 API 테스트 호스트에서 실행하여 연결·분석·모바일 모달·스와이프·숨김·수정·삭제를 확인합니다. 유료 모델의 실제 답변 품질이나 사용자의 개별 인포블록 템플릿은 자동 테스트의 범위 밖이며 설치 후 연결 확인과 주입 미리보기에서 확인하세요.

끼끼 얼굴은 마우스나 손가락으로 끌어서 이동할 수 있습니다. PC·모바일 위치를 서버에 따로 기억하며, 화면 회전·주소창·키보드·확대에 따른 실제 보이는 영역과 안전 여백 안에 맞춥니다. **확장 → 끼끼의상실 → 끼끼 위치 고정**을 체크하면 드래그가 멈추고, **끼끼 위치 초기화**로 현재 화면 크기의 기본 자리로 되돌립니다. 의상실 설정에서도 같은 옵션을 사용할 수 있습니다. 고정 중에도 화면 밖으로 나가면 안쪽으로 보정되며, 짧게 누르면 착장 말풍선이 열리고 한 번 더 누르면 닫힙니다.
